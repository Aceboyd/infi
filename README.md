# INFINI Financial Management

## Live Blog Feed

The Blog page reads current finance headlines from Finnhub on the server. Copy `.env.example` to `.env.local` and set `FINNHUB_API_KEY` before starting the development server. The page shows an editorial fallback when the key is missing or the provider is unavailable.

## Authentication setup

Add the Supabase and Resend values from `.env.example` to `.env.local`. In Supabase Auth, add `http://localhost:3000/auth/callback` (and the production equivalent) to the Redirect URLs. Password recovery is generated by Supabase and delivered with the branded Resend template in `src/lib/email.ts`; the service-role and Resend keys remain server-only.

### Profiles in the Table Editor

Authentication users are stored in Supabase's private `auth.users` schema. To also show account information in the Table Editor, run [the profiles migration](supabase/migrations/20260826000000_create_profiles.sql) in Supabase **SQL Editor**. It creates `public.profiles`, copies existing users into it, and installs a trigger so every future sign-up is saved there automatically. Do not store passwords in this table: Supabase Auth handles them securely.
